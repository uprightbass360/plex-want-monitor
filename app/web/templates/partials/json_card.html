JSON export

  • GET /api/items filters: status, type, q, author, in_feed, sort. Same filters as the tabs.
  • GET /api/items/queue.txt the queue as plain-text search strings, one per line.
  • POST /api/items/{id}/status body {"status": "queued"} to mark an item from a script.
  • GET /api/status counts, last fetch and scan, and Plex sign-in state.

Example: /api/items?status=review&in_feed=true ({{ counts.review }} items in Review right now)
